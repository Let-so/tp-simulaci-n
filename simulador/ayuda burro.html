Cola

Una sola cola con prioridad. Las camionetas siempre se atienden antes que los autos, sin importar el orden de llegada. Dentro de cada tipo: FIFO.

Distribuciones

De la fórmula al código

Llegadas — Exponencial negativa

Los tiempos entre llegadas siguen una distribución exponencial negativa. La fórmula es la transformada inversa:

X = −media · ln(1 − RND)

def next_auto(rnd=None, media=15):
    if rnd is None: rnd = random.random()
    return rnd, round(-media * math.log(1 - rnd), 4)

def next_camion(rnd=None, media=30):
    if rnd is None: rnd = random.random()
    return rnd, round(-media * math.log(1 - rnd), 4)

Tiempos de servicio — Uniforme

Frenos y Luces usan distribución uniforme. La fórmula es:

X = a + RND · (b − a)

def tiempo_freno(rnd=None, a=4, b=7):
    if rnd is None: rnd = random.random()
    return rnd, round(a + rnd * (b - a), 4)

def tiempo_luces(rnd=None, a=6, b=10):
    if rnd is None: rnd = random.random()
    return rnd, round(a + rnd * (b - a), 4)
Prioridad

Cómo las camionetas van antes

Dos listas separadas

No es una sola lista ordenada. Son dos listas. La prioridad se aplica en el momento de sacar, no de encolar.

cola_autos:    list[Vehiculo] = []
cola_camiones: list[Vehiculo] = []

Función intentar_siguiente_vehiculo()

Se ejecuta cada vez que una línea queda libre. Siempre mira camionetas primero.

def intentar_siguiente_vehiculo(linea_idx):
    f = frenos[linea_idx]
    if f.estado != ESTADO_LIBRE:
        return
    if cola_camiones:
        v = cola_camiones.pop(0)
    elif cola_autos:
        v = cola_autos.pop(0)
    else:
        return
    asignar_a_freno(v, linea_idx)
Se llama en dos momentos: al terminar Fin Frenos (si Luces estaba libre) y al terminar Fin Luces (si Frenos estaba bloqueada). En ambos casos respeta la prioridad.
Bloqueo

Qué pasa cuando Luces está ocupada

Evento Fin Frenos — dos caminos

Luces libre
→

vehículo pasa, Frenos queda Libre, entra siguiente de cola

Luces ocupada
→

Frenos pasa a BLOQUEADA, se guarda t_inicio_bloqueo

if l.estado == ESTADO_LIBRE:
    r, dur = tiempo_luces(a=luces_a, b=luces_b)
    l.estado       = ESTADO_OCUPADO
    l.fin_atencion = t + dur
    f.estado       = ESTADO_LIBRE
    intentar_siguiente_vehiculo(idx)
else:
    f.estado = ESTADO_BLOQUEADA
    t_inicio_bloqueo_f1 = t

Evento Fin Luces — desbloqueo

El vehículo sale del sistema. Si Frenos estaba bloqueada, se acumula el tiempo y el vehículo bloqueado pasa a Luces.

l.estado = ESTADO_LIBRE

if f.estado == ESTADO_BLOQUEADA:
    tiempo_bloqueada_f1 += t - t_inicio_bloqueo_f1
    t_inicio_bloqueo_f1 = None
    l.estado       = ESTADO_OCUPADO
    l.fin_atencion = t + dur
    f.estado       = ESTADO_LIBRE
    intentar_siguiente_vehiculo(idx)
La destrucción del vehículo es implícita: l.vehiculo_id = None. El objeto deja de ser referenciado por cualquier estación o cola, y el snapshot ya no lo muestra.

Dónde y cómo se calculan

Los 6 acumuladores

autos_atendidos      = 0
camiones_atendidos   = 0

La espera se acumula en asignar_a_freno()

En el momento en que el vehículo empieza a ser atendido en Frenos.

espera = t - v.hora_inicio_espera
if v.tipo == "Auto":
    suma_espera_autos += espera
    autos_atendidos   += 1
else:
    suma_espera_camiones += espera
    camiones_atendidos   += 1
Si el vehículo entra directo sin esperar, t == hora_inicio_espera y la espera es 0.

Cálculo final

Cierre

Cierre a las 16:00

La variable cerrado

Antes de procesar cada evento, el sistema evalúa si ya se llegó al cierre:

if not cerrado and t_next >= day_close:
    cerrado = True

if not cerrado:
    candidates.append((t_llegada_auto,  EVT_LLEGADA_AUTO))
    candidates.append((t_llegada_camion, EVT_LLEGADA_CAMION))

¿Cuándo termina la simulación?

Cuando no queda ningún vehículo activo en el sistema.

if cerrado:
    any_active = (
        any(f.estado != ESTADO_LIBRE for f in frenos) or
        any(l.estado != ESTADO_LIBRE for l in luces) or
        bool(cola_autos) or bool(cola_camiones)
    )
    if not any_active:
        break
El sistema no se corta a las 16:00. Se corta cuando sale el último vehículo que estaba dentro o en cola al dar las 16:00. Ese instante es la hora real de fin de jornada.
